# Sistema de Citas y Turnos Universitarios (UniTurnos)

Proyecto desarrollado para la asignatura de Ingeniería de Software I. 
Este sistema permite gestionar turnos y citas académicas para evitar filas en la universidad.

## Cómo ejecutar
1. Abrir el proyecto en Visual Studio.
2. Compilar y ejecutar el archivo principal (Program.cs).
